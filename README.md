# MSE-AWS
Smart City Information Website

Project Description

The Smart City Information Website is a simple, responsive website developed using HTML, CSS, and JavaScript. The website provides information about smart city initiatives, public services, transportation, and sustainable urban development. It is designed with a clean and user-friendly interface to help users understand the concept and benefits of smart cities.

Objective

The main objective of this project is to create an informative website that spreads awareness about smart city technologies and encourages sustainable urban development.

Features

- Responsive website design
- Home page with welcome section
- About Smart City section
- Smart City Initiatives
- Public Services
- Smart Transportation
- Contact Us form
- Registration Successful message after form submission
- Smooth scrolling using JavaScript

Technologies Used

- HTML5
- CSS3
- JavaScript (Basic)
